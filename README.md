# 西村菓子店 公式サイト

西村菓子店のブランドサイトです。お菓子、季節の商品、お知らせ、店舗案内を、あたたかい手仕事の雰囲気とともに紹介します。

## 主な機能

- PC・スマートフォンに対応したレスポンシブデザイン
- 商品、ブランドストーリー、季節商品、お知らせ、店舗案内の各セクション
- スマートフォン用ドロワーメニュー
- スクロールに合わせた控えめな表示アニメーション
- キーボード操作とモーション軽減設定への対応

## ローカルで確認する

Node.js 18以上とPython 3を使用します。外部npmパッケージへの依存はありません。

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

## ビルド

```bash
npm run build
npm run preview
```

ビルド結果は `dist/` に出力されます。プレビューは `http://localhost:4173` で確認できます。

## 公開前に差し替える項目

`index.html` 内の次の仮情報を、確定した店舗情報に置き換えてください。

- 営業時間、定休日
- オンラインストアURL
- Instagram URL
- 問い合わせ先メールアドレス
- お知らせの内容と日付

商品写真を用意した場合は、現在のCSSイラストを写真へ置き換えられます。
